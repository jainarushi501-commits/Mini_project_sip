Limitations
  • No machine learning is used, so detecting modern AI-generated images with hand-made features is unreliable.
  • Social media and messaging apps recompress images, which weakens most forensic traces.
  • The default thresholds are uncalibrated. Use the calibration script and report the measured accuracy.
  • The confidence value is a rule margin, not a probability. "Likely authentic" never proves authenticity.
